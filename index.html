To see each other’s photos from different phones, connect a free Firebase database. It takes about 10 minutes and you only do it once.

  1. Go to console.firebase.google.com, sign in with a Google account and click Create a project. You can switch Google Analytics off.
  2. In the left menu open Build → Firestore Database and click Create database. Pick Standard edition, the location closest to you, and production mode.
  3. Open the Rules tab, replace everything with the rules below and click Publish.
  4. Click the gear icon → Project settings. Under Your apps click the </> (web) icon, give it any nickname and register it.
  5. Paste the const firebaseConfig = { … }; block over the one at the top of script.js (without the import lines), or paste it to Claude and ask for it to be added.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /posts/{id} {
      allow read, write: if true;
    }
    match /photos/{id} {
      allow read, write: if true;
    }
  }
}
